1. THE ORIGINAL CONFLICT
----------------------------------------------------------------------
The finalized calibration contained two side-qualified plain-hip rows,
both routed to Body:
  bip_r_hip  -> groupFile/Body   (CLEAR/CLEAR)
  l hip spo  -> groupFile/Body   (CLEAR/CLEAR)

The live Master's own existing precedent for word-boundary "hip" splits
cleanly by side-qualification:
  Bare/unsided forms -- 4/4 -> groupFile/Body:
    hip, Hip, hip.base, hip.root
  Explicitly sided forms -- 6/6 -> groupFile/Legs:
    hip.l, hip.r, Ab-L-Hip, Ab-L-Hip-Reg, Ab-R-Hip, Ab-R-Hip-Reg

The two calibration rows are both side-qualified yet both landed on
Body, directly contradicting the Master's own sided-hip convention.

rather than resolved in either direction during the targeted QA pass.

----------------------------------------------------------------------

----------------------------------------------------------------------
3. ANIMATOR-FACING RATIONALE
----------------------------------------------------------------------
A central/unsided hip control behaves as a single pelvis/torso anchor
-- there is only one of it, it has no leg-specific counterpart, and it
functions as body/torso structure. An explicitly left- or right-sided
hip JOINT is, from an animator's workflow perspective, the proximal
end of that side's leg chain -- the same way a shoulder is grouped with
the arm it articulates rather than with the torso, a sided hip belongs
with that side's leg controls. This mirrors the Master's own existing,
self-consistent split and gives animators a single predictable place to
find "the hip control for the left/right leg" alongside the rest of
that leg's rig.

----------------------------------------------------------------------
4. EXACT NARROW RULE ADOPTED
----------------------------------------------------------------------
Recorded as Rule 26 in both PHASE2_SEMANTIC_RULEBOOK_FINAL.txt and
PHASE2_SEMANTIC_BATCH_RULES.txt (identical text, keeping the two files
byte-synchronized as they have been since the original freeze commit --
see Section 7 below):

  Central/unsided hip-pelvis structure -> Body.
  Explicitly left/right-sided hip joint/articulation -> Legs.
  Helper/buffer/front/base qualifiers and numeric suffixes do not by
  themselves change this destination.
  NARROW: does not generalize to "any L/R + hip token -> Legs."
  Explicit overrides preserved: buttock/ass/butt -> Body regardless of
  side marker; hip/butt shape or size morph -> Body Morphs; garment-
  owned hip control -> Clothing; explicit repair/correction purpose ->
  Correctives; any hip phrase that is not plainly a structural hip-
  pelvis/hip-joint control is resolved by ordinary context rules.
