J. ORDERING METHOD (applied uniformly, whole Master)
------------------------------------------------------------------------
Within each group's own direct control list (each contiguous run,
independent of any sibling subgroups), controls were ordered by:
  1. protected root/global anchor (root_transform only), if present and
     already first
  2. explicit special exception (bip_toe_l / bip_toe_r), if applicable
  3. in the seven target paths only: FLEX region before BONE region
  4. within each resulting region (or the whole run, for non-target
     groups): natural alphanumeric sort (ASCII case-insensitive, numeric
     chunks compared as integers so item2 < item3 < item10) with a narrow,
     conservative bilateral-adjacency pass -- only exact prefix (l_/r_,
     L_/R_), exact suffix (_l/_r, _L/_R, .l/.r, .L/.R), or exact whole-word
     (Left/Right, left/right, LEFT/RIGHT) marker swaps were treated as
     "obvious" pairs and kept adjacent (matching stem's natural-sort
     position); anything not matching one of these exact patterns was
     natural-sorted as a standalone item, per instruction not to infer
     relationships that aren't obvious.
No family-inference system, token scorer, or semantic classifier was built
or used for ordering -- this is a fixed, narrow pattern list applied
identically everywhere.
