  lipul, lipur         -- immediately adjacent to the lipUpper_L1..4 /
                          LipUpperInner_L/R / LipUpperOuter_L/R series

This is a coherent parallel TEMPLATE, not a single isolated bilateral
pair: "lip" + {d|u} + {l|r}, where the first letter systematically
tracks Lower/Upper (matching the adjacent fully-spelled series in the
same corpus) and the second letter tracks the side convention (l/r)

lipUpper_L/R, LipNasolabialCrease_L/R, etc.). Two independent
same-template pairs corroborating the same two-axis code is stronger
grounding than a single isolated L/R pair (which would only prove
systematicity, not decode meaning) -- this satisfies Rule 23's
"demonstrably coherent naming series/template in the same corpus"
grounding test (23c).

regardless of upper/lower distinction -- there is no separate "Upper
Face" convention for lips. The proposed destination matches actual
Master precedent, not merely the task's illustrative suggestion.

Conclusion: sufficiently grounded. lipur is reclassified:
  semantic_status:      OPAQUE -> CLEAR

                         direction+side shorthand paralleling
                         lipUpper_R1..4 / LipUpperOuter_R /
                         LipUpperInner_R)"
  taxonomy_status:       NOT_APPLICABLE -> CLEAR
  proposed_destination:  [blank] -> groupFile/Face/Lower Face

----------------------------------------------------------------------
Only "bip collar l" exists as a row in the 500-family pilot; "bip

Live-Master evidence for the bare, unqualified underscore form

  bip_collar_L, bip_collar_R, Bip_Collar_L, bip_Collar_l,
  bip_collar_l, Bip_Collar_R, bip_collar_r  -> ALL 7/7 -> groupFile/Arms

bip_collar_def_L/R (a "_def"/deform-bone marker), bip_collar_L1/L2/L3,
bip_collar_L_twist_01, bip_collar_L_root. The residual corpus itself
contains a parallel "bip_collarhelper_l/r" pair -- "helper" bones are
a rig/anatomy satellite-bone pattern, not a garment pattern.

The standard Source-engine ValveBiped clavicle-bone naming convention
also appears in the residual corpus (Valvebiped.L_collar,
Valvebiped.R_collar), corroborating that bare biped "collar" is a
recognized rig/DCC convention for the clavicle/shoulder-girdle bone
(Rule 23b).

By contrast, every clearly-garment "collar" found in both the Master
and the residual corpus carries an explicit qualifier the target
literal lacks: jacket_collar_*, cloth_collar_*, bip_ClockCollar_*
(named costume), bip_BellCollar_* (named costume), bip_collar_L_cloths
/ bip_collar_1_L (explicit "_cloths"/segment-numbering garment
pattern), "collar front/back/side left/right" (spatial multi-segment
cloth-sim phrasing), CollarFur2SuitMH3 (explicit "Suit"), L/R CollarA/
B/C a Phy (explicit physics-sim marker).

Conclusion: the original Clothing/High classification was not
adequately grounded -- in fact the evidence points the other way. The
bare, unqualified form matches the biped anatomical clavicle-bone
convention exclusively (100% of exact Master precedent), while every
garment reading in this corpus requires an explicit qualifier this
literal does not have. Reclassified as Arms (interpretation B):
  semantic_referent:     "left clothing collar" -> "left clavicle/
                          shoulder-girdle rig bone (biped 'collar'
                          bone)"
  proposed_destination:  groupFile/Clothing -> groupFile/Arms
  confidence:            High (unchanged -- the exclusive 7/7 Master
                          precedent plus the ValveBiped convention and
                          the sibling "collarhelper" pattern is
                          decisive, not merely "plausible")
  short_reason:          updated to state the evidence above

semantic_status and taxonomy_status remain CLEAR (unchanged) -- only
the interpretation and destination change.

Disposition: Category C (taxonomy/destination correction).

Two adjacent rows were also inspected as part of this sweep and found
