4. JUDGMENT: DONGER04_CHAIN
----------------------------------------------------------------------
The external review's core objection is confirmed correct: "donger" is
not an ungrounded/cryptic prefix, and Rule 24 (discard an ungrounded
prefix, classify what remains) does not apply to it -- Rule 24's own
precondition (the discarded token is actually ungrounded) fails here.
The original Tranche 3 audit's own proposed fix (discard "donger",
classify "chain" alone as PARTIAL/NEEDS_CONTEXT) reached the right
taxonomy_status by lucky coincidence but for the wrong reason, and
underclaimed what is actually known about the row.

Per instruction, "donger04" and "donger04_chain" are different strict-
ASCII families -- Donger04's destination is NOT copied by identity.
Instead, the GROUNDING that "donger" = penis/genital-region naming
transfers as semantic precedent, exactly as the task specifies. What it
establishes: the OWNER/region (penis/genital) is now known. What it
does NOT establish: which sense of "_chain" applies -- physics/jiggle-
simulation chain (would suggest Body, ordinary dynamics/structural
control), a decorative/worn chain (would suggest Clothing), or a
mechanical/rig chain unrelated to either. Nothing in the literal or in
either evidence source disambiguates "_chain" the way it disambiguates
"donger."

Verdict: Option B. OPAQUE/NOT_APPLICABLE does not survive -- it cannot
be reconciled with the demonstrated grounding of "donger" (an OPAQUE
verdict asserts no reliable core referent exists at all, which the
34/35 Master precedent and the Silkworm "Penis Bones" group membership
directly contradict). Option A (CLEAR/CLEAR/Body) is NOT adopted either,
because "chain"'s own multi-sense ambiguity is not resolved merely by
knowing the owner, and forcing a destination would repeat the exact
error (confident selection without genuine grounding) this task exists
to correct.

Method: a Python script enumerated all 133 Tranche-3 OPAQUE rows,
tokenized each fold_key into alphabetic substrings (length >= 4,
excluding a stopword list of known rig/technical terms already
